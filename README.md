
# Quantity Estimator

A Streamlit-based application that extracts room dimensions from floor plan images using OCR
and generates quantity estimation and cost analysis.

## Features
- Floor plan image OCR
- Automatic dimension extraction
- Unit conversion (feet to meters)
- Material quantity & cost estimation
- Interactive analytics & charts

## Tech Stack
- Python
- Streamlit
- Tesseract OCR
- Plotly
- OpenCV

## How to Run
```bash
pip install -r requirements.txt
streamlit run quantity_estimator2.py
